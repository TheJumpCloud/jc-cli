The upstream documents the generated artifacts in this repo were built from. There is deliberately no date here — git holds that, and more reliably than a self-reported string:

```
git log -1 --format=%ad -- docs/API_COVERAGE.md
```

A date in the file would also defeat `make verify-generated`, which regenerates these artifacts and fails on any difference: every regeneration would differ and the check could no longer tell a moved spec from a rerun script.

The digest covers the whole document, so upstream reformatting or an edited description moves it while nothing jc derives changes. That is the point of the split: this file answers *is it the same document?*, and the regenerated artifacts answer *did anything we depend on change?*. A drift PR whose only diff is a digest means upstream republished and jc is unaffected.
